GUIDED SETUP

How setup works

  1. 1
    Find the extension ID

    Open Chrome’s extensions page, turn on Developer mode, and copy the ID of the candidate’s installed extension.

  2. 2
    Choose a history folder

    Enter its full local path. Use Test folder in the candidate window before saving.

  3. 3
    Add the prompt template

    Paste the candidate’s complete prompt template. It is stored separately from the other candidates’ templates.

  4. 4
    Set the candidate active

    The active candidate’s folder and template are used when the extension captures a job.
